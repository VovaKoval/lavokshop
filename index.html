📷 Instagram & Чат з сайту

Повідомлення з чату на сайті (shop.html) надходять сюди автоматично через Google Sheets. Instagram Direct потребує Meta Business API.
✅ Чат з сайту → CRM: працює через Google Sheets (polling кожні 30 сек)
⚠️ Instagram Direct: потребує Meta Business API (налаштовується окремо)

🔑 API Ключі та інтеграції

Вставте API ключі для зовнішніх сервісів. Система автоматично підтягне їх при потребі — вам не потрібно правити код.
